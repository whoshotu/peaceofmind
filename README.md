# peaceofmind

**Agent Society – Multi‑Agent Collaboration Platform**

_An open‑source intelligent assistant for content creators that combines a customer‑service bot, a content‑manager, a daily creator assistant, and a generic runner for external services. Built on Qwen Cloud, orchestrated with Temporal, and deployed on Alibaba Cloud via ROS._

---

## Project Overview

- **Primary track:** **Agent Society**
- **Programming language:** Python (FastAPI + Temporal) and React for the UI.
- **LLM:** Qwen Cloud (function‑calling mode) powers all agents.
- **External integrations:**
  - **Alibaba Cloud SMS** (proof of Alibaba Cloud usage).
  - **PayPal Sandbox** (payment verification).
  - **OSS** (stores a tiny log file generated by the SMS adapter – this file is referenced in the submission as proof of Alibaba Cloud deployment).
- **Persistence:** PolarDB (memory store) + Redis (task queue).
- **Deployment:** Alibaba Cloud ROS template (`infra/ros_template.yaml`) creates a VPC, an ACK cluster, an API Gateway, an OSS bucket, and a RAM role with the necessary permissions.
- **Orchestration engine:** **Temporal** – provides reliable workflows, retries, and built‑in human‑in‑the‑loop checkpoints.

## Quick‑Start (Local Development)

> **Prerequisites**
> - Docker & Docker‑Compose installed.
> - Python 3.11+, Node 20+, ROS CLI (`pip install aliyun-cli`).
> - Qwen Cloud API key (`export QWEN_API_KEY=YOUR_KEY`).
> - Alibaba Cloud credentials (`ALIBABA_ACCESS_KEY_ID` & `ALIBABA_ACCESS_KEY_SECRET`).
> - PayPal sandbox credentials (`PAYPAL_CLIENT_ID` & `PAYPAL_CLIENT_SECRET`).

1. **Clone the repository**
   ```bash
   git clone https://github.com/whoshotu/peaceofmind.git
   cd peaceofmind
   ```

2. **Deploy Alibaba Cloud resources**
   ```bash
   roscli validate -f infra/ros_template.yaml
   roscli deploy -f infra/ros_template.yaml
   ```
   Take note of the generated API Gateway URL – you will need it for the next step.

3. **Start Temporal (single‑node for dev)**
   ```bash
   docker run -d --name temporal -p 7233:7233 temporalio/auto-setup
   ```

4. **Build and run the backend & frontend**
   ```bash
   docker compose up -d  # uses backend/Dockerfile & frontend/Dockerfile
   ```

5. **Access the UI**
   Open `http://localhost:5173` (Vite dev server) or the public URL exposed by the ACK service.

## Testing the End‑to‑End Flow

1. Open the UI and type a viewer question, e.g., *"I paid for the premium video but can't see it"*.
2. The **CustomerServiceAgent** will call Qwen Cloud, detect low confidence, and create a pending task.
3. In the *Admin* panel, click **Approve** – the workflow proceeds.
4. The **AllPurposeRunnerAgent** verifies the PayPal order (sandbox) and, on success, triggers the **SMSAdapter** which sends an SMS and writes a tiny log file to the OSS bucket.
5. The final response is displayed in the chat window.

You can also test the **ContentManagerAgent** by typing *"Schedule my draft for tomorrow 10 am"* and observe the OSS upload and calendar entry creation.

## Agents Overview

| Agent | Responsibility |
|-------|-----------------|
| **CustomerServiceAgent** | Answers viewer questions, flags ambiguous inputs, routes to Human‑In‑The‑Loop when needed. |
| **ContentManagerAgent** | Organizes drafts, adds tags, schedules posts, moves assets in OSS. |
| **CreatorAssistantAgent** | Daily reminders, calendar sync, suggests next content ideas based on stored preferences. |
| **AllPurposeRunnerAgent** | Executes external actions – PayPal verification, Alibaba Cloud SMS, OSS uploads – on behalf of the other agents. |
| **NegotiationMediatorAgent** *(optional)* | Resolves conflicts when multiple agents propose competing actions. |
| **MemoryCleanerAgent** *(background)* | Periodically removes stale entries from the PolarDB memory store. |
| **HumanInTheLoopAgent** | Presents ambiguous tasks to a human reviewer via the admin UI and records the decision. |
| **AnalyticsReporterAgent** *(optional)* | Generates daily/weekly summary reports on tickets, payments, SMS, and agent efficiency. |
